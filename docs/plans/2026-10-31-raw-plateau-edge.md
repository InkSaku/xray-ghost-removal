# 10.30 RAW 顶格区边缘衰减模型 Medge（预先固定设计）

2026-10-31 在实现和运行前写定。只用现有数据。

## 动机与已知信息

- Msplit（RESULTS第10节）是基线：`预测 = s × G + (1 − s) × (a × Xu + b)`，边界层误差最大（中位517计数）。
- RESULTS第11节：换哪种未顶格响应曲线，边界块的平均残差都随 `Xu` 从约−126降到约−575，即一致高估，不是未顶格曲线造成的，而是边界块里顶格部分按 `G` 预测偏高。
- RESULTS第12节：未顶格区的残影与曝光关系很弱，"靠近顶格区多出残影"不成立。
- 两种解释都预测"紧邻物体边缘的顶格像素残影比空气中央弱"：这些像素的真实曝光可能只略高于55000；或残影在空间上被周围物体区稀释。本轮不区分二者，只检验这一现象能否稳定建模。

## 研究问题

顶格像素的残影是否随它到最近未顶格像素的距离减小而变弱？用一个随距离衰减的因子修正 `G`，能否在留出配对上明显优于Msplit，尤其是边界层？

## 输入与定义

输入、干净暗帧、70组配对、16×16分块、`s`、`Xu` 与Msplit相同。新增一个只由前一帧算出的特征：

- 在全分辨率上，对每个顶格像素（等于55000）计算它到最近非顶格像素的欧氏距离 `d`（像素）。
- 对每个λ，`E_λ` = 分块内顶格像素上 `exp(−d/λ)` 的平均；`s=0` 的块为0。`E_λ` 越大，说明该块的顶格像素越靠近物体边缘。
- `d` 只用作解释变量，不删减、不排除任何像素或分块，不违反项目"禁止外扩排除区"的规定。

## 模型

**Medge**

```
预测 = s × G(位置) × (1 − κ × E_λ) + (1 − s) × (a × Xu + b)
```

- `a, b` 与Msplit相同，只用训练配对 `s=0` 的块拟合。
- 对每个λ（2、4、8、16、32、64、128、256像素），交替拟合 `G` 与 `κ`，直到κ两轮之间的变化小于1e−4（最多300轮）：
  1. 给定κ，`G` 在每个位置取训练配对中 `s=1` 块的最小二乘值 `Σ Y·m / Σ m²`，`m = 1 − κE_λ`；样本少于3个的位置按Msplit同法从已有位置插补；
  2. 给定 `G`，κ用训练配对所有 `s>0` 块的最小二乘求得，目标为 `Y − (1 − s)(a·Xu + b)`。
  初值κ=0（即Msplit的 `G`）。λ取训练误差最小者。留出配对不参与任何一步。

**实现前修订（2026-10-31，尚未运行任何真实数据）**：原写"固定5轮"。合成数据单元测试中，埋入κ=0.4时5轮只到0.21、20轮0.385、100轮才收敛到0.3999：`G` 与κ强耦合，交替拟合收敛很慢。因此改为按收敛条件停止，并在结果中记录每次拟合的轮数和是否收敛。判定门槛未改。

## 预先固定的判定（S1，同目录留一配对，70组）

Medge **取代Msplit成为新基线**，需同时满足：

1. 逐配对RMSE比（Medge / Msplit）中位 ≤ 0.95；
2. 至少42/70组RMSE低于Msplit；
3. 边界层中位RMSE ≤ Msplit的0.90倍；顶格层和未截断层中位RMSE都不高于Msplit的1.01倍；
4. 可辨识：至少63/70次拟合满足 0 < κ ≤ 1，且至少63/70次选中的λ不在网格两端（2或256）。

未通过时Msplit保持基线，不调整门槛或网格。

## 描述性诊断（无门槛）

- 边界块按 `Xu` 分箱的平均残差（Msplit与Medge），对照第11节的高估趋势。
- 顶格块按块内平均距离分箱的平均残差。
- 各目录选中的κ、λ分布。
