# 10.30 RAW 未顶格区响应形状：NLCSC 式饱和曲线与幂律（预先固定设计）

2026-10-31 在实现和运行前写定。现阶段只使用已有数据，不依赖补采。

## 背景与已知信息

Msplit（RESULTS第10节）是这批RAW的基线：`预测 = s × G + (1 − s) × (a × Xu + b)`，未顶格部分是直线。文献中 Starman 2012 的 NLCSC 让残影系数随曝光量按饱和型曲线 `c₁(1 − e^(−c₂x))` 变化（Med Phys 39:6035）。NLCSC 的完整形式还需要多帧时间序列和存储电荷跟踪，这批数据每次曝光只有一张暗帧，无法检验；本轮只检验它的曝光响应部分。

写定前已知、且会影响预期的信息：

- RESULTS第9节的事后探索中，未顶格块各自拟合直线后，分箱残差基本平坦。因此在未顶格块内，非线性带来的改善预计有限。
- 只看高值帧（不涉及残影）统计：未顶格块的 `Xu` 中位约6,300、第90百分位约26,500；边界块未顶格像素的 `Xu` 中位约37,500、第90百分位约50,600。直线主要由低 `Xu` 学得，在边界块的高 `Xu` 上是外推，所以响应形状若有影响，主要体现在边界层。
- NLCSC 的饱和型曲线是上凸的（低曝光时增长快、高曝光时变缓）。顶格区残影远强于未顶格区的趋势方向相反，因此同时检验一个可以下凸的幂律作对照。

## 研究问题

未顶格像素的残影对曝光的响应，偏离直线吗？如果偏离，是 NLCSC 式的上凸饱和，还是下凸？换用非线性曲线能否在留出配对上明显优于 Msplit？

## 输入与固定部分

与 Msplit 完全相同：142张RAW、干净暗帧、70组配对、16×16分块、`s`、`Xu`、位置图 `G` 的学法、同目录留一配对（S1）、0.5/99.5百分位训练修剪。只替换未顶格部分的函数 `f(Xu)`：

```
预测 = s × G + (1 − s) × f(Xu)
```

## 候选

| 模型 | f(Xu) | 非线性参数网格 |
|---|---|---|
| Msplit（基线） | `a·Xu + b` | — |
| Msat（NLCSC 式） | `c·(1 − e^(−Xu/τ)) + b` | τ 取2,000到500,000的对数等距40点 |
| Mpow（对照） | `c·(Xu/55000)^p + b` | p 取0.25到4的对数等距40点 |

拟合只用训练配对中 `s=0` 的块，先按Msplit同样的修剪规则筛选。对每个网格值用最小二乘求 `c, b`，取训练误差最小的网格值。留出配对不参与修剪、网格选择或系数拟合。τ很大时Msat趋于直线，p=1时Mpow即直线。

## 预先固定的判定

候选**取代 Msplit 成为新基线**，需在S1全部70组上同时满足：

1. 逐配对RMSE比（候选 / Msplit）中位数 ≤ 0.95；
2. 至少42/70组（60%）RMSE低于Msplit；
3. 未截断层与边界层的中位RMSE都不比Msplit高出1%以上（顶格层按构造相同，只报告）；
4. 可辨识：70次留一拟合中至少90%（63次）选中的网格值不在网格两端。

两个候选都通过时，取全图中位RMSE较低者。都未通过则Msplit保持基线，只报告结果，不调整门槛或网格。

## 描述性诊断（无门槛）

- 未截断块和边界块分别按 `Xu` 分箱，报告三个模型的平均残差。
- 各模型在70次留一中选中的 τ、p 分布；p>1 表示下凸，p<1 或有限 τ 表示上凸。
- 去掉11组预标记配对后重算判定，作为敏感性分析。
