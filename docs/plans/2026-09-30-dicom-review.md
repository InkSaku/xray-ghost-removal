# DICOM 阅片、截断与噪声检查

## 本轮边界

先验证已有全分辨率 `seamless` 去除器，仅使用紧邻前一帧。它不是最近在冻结
16×16 网格上研究的 M1；不能把分块预测直接放大后宣称得到了全分辨率恢复。
本轮不重算背景、不修改冻结配置、SAM archive 或正式 M1 审计记录。

`outputs/` 检查后没有对应阅片包的前身。新建稳定非版本路径
`outputs/dicom_review/`，与旧 `data/processed/seamless_cleaned/` 的多帧结果分开。
旧结果被历史 RESULTS 引用，保留以复核历史结论，不混入这批交付。
同一定义下重新运行覆盖本路径；只清理由本脚本生成且不再使用的查看副本/对照图。

## 运行

```bash
.venv/bin/python scripts/prepare_dicom_review.py
```

输入为 `data/raw/残影图像/1.dcm` 至 `30.dcm`。生成：

- `selection.json`：先看输入、后运行算法的样本选择，30 张原图和实现代码哈希。
- `dicom/`：像素一致的原图查看副本、前序参考副本、单帧处理副本。
- `NN_comparison.png`：原图确定的全局/背景窄窗，对照共享窗口，固定色标差值。
- `review_results.json`：导出读回核对、原图哈希复核、截断/噪声/边缘代理统计。
- `review.md`：老师可读的检查表与阅片说明。

样本规则：历史 4/6/18、未处理导出对照 1、观测最大值堆积最明显的目标与其后继、
排除明显最大值堆积后输入空气区分块相关绝对值最小者。堆积筛查阈值为 0.1%，
是检查线索，不是过曝诊断标准。弱相关也不代表真实无残影。
选样不使用处理后改善幅度；`selection.json` 在去除器运行前落盘。

## 导出处理

30 张原始文件共用一个 SOP Instance UID，缺少 Study/Series UID，不能原封不动
沿用身份字段。查看副本使用 Secondary Capture SOP Class、同一新 Study、各自唯一
Series/SOP UID。原图像素保持一致；处理图通过 SourceImageSequence 引用当前和前序
查看副本。源文件对应关系通过文件名及 SHA-256 记录。未伪造缺失的采集信息。

导出接受存储像素单位的二维无符号 8/16-bit 单色数组，保留有效位深与灰度变换；
先统计越界，按 BitsStored 裁剪、四舍五入，再写入 Explicit VR Little Endian。
重新读取并逐像素验证。NaN、尺寸变化、多帧、彩色、有符号输入明确拒绝。
此工具完成当前研究查看副本的检查，不是所有医学 IOD 的通用合规认证工具。

去除器增加 `clip_output=False` 诊断选项，默认行为保留；本轮使用该选项以免提前
裁剪掩盖超限。旧入口 `run_ghost_removal.py` 默认历史帧数改为 1；显式指定多帧仍可
复现旧结果。研究主线仍是单帧。

## 评价边界与后续

噪声 ROI 来自原图的非饱和、低变化空气区，并固定给处理图使用；计算水平/垂直邻差
MAD、高频标准差及相邻相关。该选区偏向低噪声，不能代表全图；无合格 ROI 则报告未验证。
边缘梯度比和物体重叠区改变量只用于提示需要人工审查的位置，不能证明细节保留。
候选残影区分块标准差不能当作真实残影去除率。

尤其检查低于 65535 的观测最大值堆积：本批多张文件停在 55000。不能由此区分成像板
饱和、读片映射或后处理裁剪；须结合设备记录或补采。已截断的 source 不保证支持线性
模板扣除。系数碰上限和饱和输入必须在检查表中暴露，不把“已执行”记作“通过”。

完成 Horos 导入和固定窗口检查后，另记实际观察与仍未验证事项。只有针对具体失败
模式取得证据后才调整算法；恢复准确性最终仍需真实 clean/previous/ghosted 三元组。
