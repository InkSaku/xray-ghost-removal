# 10.30 RAW 顶格/未顶格分区模型 Msplit（预先固定设计）

2026-10-30 在实现和运行前写定。动机来自 `2026-10-30-raw-m1-cross-pair.md` 的结果：M1参数可跨配对迁移，但仿射形式不充分；平台区（前一帧像素等于55000）输入为常数，M1只能给出一个固定预测，而实测残影上强下弱；未截断区只用自身数据拟合的斜率约0.002，远低于全图的0.043。

写定前只额外统计过高值帧的平台覆盖（不涉及任何低值帧或残影）：三个目录中，留一配对后仍有至少5个完全平台训练样本的分块比例分别为97.6%、100%、100%；每组边界分块（0<s<1）占比中位8.9%，平台75.0%，未截断16.2%。

## 研究问题

把平台区和未截断区分开建模，能否在留出配对上明显优于M1？未截断区的残影是否确实依赖前一帧像素值？

本轮不回答：平台区真实曝光量、55000来源、物理衰减常数、曝光图去除后的恢复率。

## 输入与定义

与M1检验完全相同，不改变：142张RAW只读，`<u2` 3072×3072，16×16分块；干净暗帧 `D` 为 `20000039`、`200000C0` 分块均值的平均；`Y = 低值帧分块均值 − D`；70组同目录相邻配对及同样的两类预标记。

每个分块由高值帧全分辨率像素另算两个量，只做阈值计数和平均，不做任何形态学操作：

- `s`：像素等于55000的比例；
- `Xu`：该块中不等于55000的像素的平均值减去 `D`；`s=1` 时无定义且不使用。

## 模型

**Msplit**

```
预测 = s × G(位置) + (1 − s) × (a × Xu + b)
```

- `G`：逐分块位置图。对每个分块，取训练配对中该块 `s=1` 的全部 `Y` 求算术平均。训练样本少于3个的分块，用 `m1.fitting._weighted_lowpass` 以已有分块为权重依次按σ=2、4、8、16、32分块插补，只填空缺，不改动已有值。
- `a, b`：只用训练配对中 `s=0` 的分块，沿用 `m1.fitting` 的0.5/99.5百分位训练修剪和最小二乘。
- 边界块不参与学 `G` 和 `a, b`，只在预测时按 `s` 混合。

**对照**

- **M1**：`Y = alpha × X + b`，与上一轮完全相同，在同一次运行中重算。
- **Map-only**：`预测 = s × G + (1 − s) × c`，`c` 为训练配对 `s=0` 分块的平均 `Y`，不使用前一帧像素值。用于检验 `a × Xu` 是否有贡献。

## 评价方案

- **S1（主要）**：同目录留一配对，`G`、`a`、`b`、`c` 和M1参数只用同目录其余配对；留出配对的 `Y` 不参与任何训练、修剪或插补。
- **S2（描述性）**：留一目录，用另两个目录全部配对训练，不做幅度缩放。

逐配对报告全图和平台、边界、未截断三层的RMSE与R²，以及平台区逐行平均残影的预测/实测相关（衡量能否画出上下渐变）。

## 预先固定的判定

**Msplit 晋升为RAW新基线**需同时满足（S1，全部70组）：

1. 逐配对RMSE比（Msplit / M1）的中位数 ≤ 0.80；
2. 至少63/70组（90%）Msplit RMSE低于M1；
3. 未截断层与边界层的中位RMSE都不高于M1。

**像素值项是否保留**：若Msplit未截断层的中位RMSE没有比Map-only低至少5%，判定 `a × Xu` 无实质贡献，此时改由Map-only对照按上面1–3条判定是否晋升（更简单的形式优先）。

两者都未通过时只报告未通过，不调整门槛。全图R²是否达到0.90只作描述，不作门槛。

## 敏感性与描述

- 去掉11组预标记配对后重算判定，不替代主要结论。
- 按目录分别报告；200mA目录文件名间隔变化较大，单独说明，不拟合时间项。
- `G` 的稳定性：三个目录各自全部配对学出的 `G` 两两相关，以及与M1检验中平均残差图的相关。
