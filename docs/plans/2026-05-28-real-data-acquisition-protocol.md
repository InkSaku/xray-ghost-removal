# DR 平板 X 射线探测器单帧残影研究数据采集与交付

> 修订日期：2026年10月13日
> 设备已确认为 **DR 平板探测器**。本文件直接更新原2026-05-28采集协议，作为本轮执行口径；历史CR光擦除流程不适用于本轮。
> 本轮目标：用少量、条件明确且可重复的数据，测量一次曝光后的第一帧残留，探索曝光响应，并支持简单去除模型的初步验证。

## 一、执行前必须确认的设备与采集定义

本轮不要求大规模采集。请先完成 **2组曝光试拍（低、高各1组）**，并反馈背景恢复、第一帧取得能力、时序及像素量程；正式采集前确认下表事项。试拍条件、流程和记录与正式要求完全一致并通过检查时，可计入对应正式组，注明其试拍身份，避免重复计费；否则单独交付并说明问题。

| 确认事项 | 交付说明 |
| --- | --- |
| 探测器 | 已确认是 **DR**。提供准确厂商、型号、探测器编号、转换结构及传感器类型（设备可提供的真实信息，如间接转换/a-Si、直接转换/a-Se、CMOS等），是否支持连续读出、原生帧率与本轮采用的实际模式。 |
| Dark的真实含义 | 本研究统一采用 **射线源 OFF** 模式。Light/Flood曝光帧后，在关束状态下取得第一张实际无新曝光读出帧，记为 `dark_01`。企业需确认设备能否执行；若无法实现，请在正式采集前反馈。 |
| 第一帧取得能力 | `dark_01` 必须是曝光帧后的第一张实际暗读出帧，不能只是第一张导出的图片。确认是否存在隐藏读出、清空帧、丢弃帧、自动暗场校正帧；保存实际帧编号和事件日志。存在中间读出时如实反馈，不能把后续帧重命名冒充第一帧。 |
| 图像处理链 | 逐项说明 offset、gain、坏点校正、自动暗场更新、LUT、非线性灰度映射、截断、平滑及设备内置残影校正。优先提供保留原始像素数值的原生全分辨率无损DICOM或可解码厂商原始数据，尽量关闭内置残影校正及非线性增强；常规offset/gain/坏点校正可保持固定一致，但须说明。若不能关闭内置残影校正，先反馈，此时研究对象为该设备校正后的剩余残留，不能称为未校正原始残影。 |
| 读出与积分 | 固定并记录帧率/帧周期、积分时间、触发方式、读出模式、binning/ROI模式。Dark的积分窗口应处于射线OFF阶段；若有混合曝光帧或拖尾曝光，单独标记并反馈。 |
| 时间与复位能力 | 记录曝光结束至每张曝光后Dark开始读出的实际间隔（ms），并明确积分与读出事件含义。优先设备时间戳/日志；无法直接导出时提供可靠外部计时及精度说明。确认设备可以按同一流程恢复稳定背景，并支持独立重复。 |

**执行原则：** 使用企业现有测试物体和设备允许的测试模式；固定流程优先于增加图像数量。研究性重复曝光在专用测试物体/模体上执行。

## 二、数据的具体采集操作与交付数量

**请采集人员按照本节操作、保存原始图像并填写记录。**

研究对象固定为：**单次曝光后、射线源OFF条件下的第一张暗读出帧 `dark_01`**。本轮交付 A（有物体单次曝光）、B（无遮挡单次曝光）及 S（无曝光流程对照）三包。

### 2.1 图像名称：分别怎么拍

| 文件名中的名称 | 实际要做的事 | X射线源状态 |
| --- | --- | --- |
| `clean_before` / `clean_after`（背景暗图） | 在设备恢复稳定状态后，不曝光，按固定模式读取背景 | **OFF** |
| `light`（A包）/ `flood`（B包） | A包放测试物体，B包不放物体，只进行一次实际曝光 | **ON** |
| `dark_01`（第一张曝光后暗图） | 曝光帧后关束，按约定模式取得第一张实际暗读出帧 | **OFF** |
| `dark_02`（第二张曝光后暗图） | 延续相同模式取得下一张暗图，期间不追加曝光 | **OFF** |
| `sham_dark_01` / `sham_dark_02`（S包对照） | 无实际曝光，但尽量匹配曝光实验的触发、等待和读出流程，取得两个对应位置的暗图 | **OFF** |

本轮共 **17次实际X射线曝光**。符合正式条件的试拍可计入上述组数；无法计入的试拍、设备自动产生的额外帧，另外标记数量，不重复计算独立实验。

**辅助帧可保留：** 若 `dark_03`、`dark_04` 自动保存几乎不增加人工成本，可继续保存并记录，不必删除。A/B全部保留这两张时，核心169张之外增加34张，合计203张；独立循环和实际曝光次数不变。设备正常复位所需的实际读出流程不得为了减少交付张数而随意改变。额外隐藏/校正/辅助帧的次数、时序须记录，可取得时一并提供。

**本轮数量是预实验起点。** 先检查残留是否可测、背景是否稳定、重复是否一致，再决定是否补采中间曝光档、更多重复或跨日期确认，不预先承诺这批数据足以建立通用规律。

### 2.3 曝光档位与采集顺序

正式拍摄前通过试拍确定3套实际参数：`L1`（低）、`L2`（中）、`L3`（高）。**A使用L1、L3；B使用L1、L2、L3。** 三档均应在设备允许的有效量程内，避免截断或大面积顶格。

| 档位 | 管电压kV | 管电流mA | 曝光时间ms | 实际mAs | 入射量/条件标定（可提供时） | 用于哪一包 |
| --- | --- | --- | --- | --- | --- | --- |
| L1（低） | 待试拍确认 | 待试拍确认 | 待试拍确认 | 待计算/核对 | K（μGy）或对应标定编号 | A、B |
| L2（中） | 待试拍确认 | 待试拍确认 | 待试拍确认 | 待计算/核对 | K（μGy）或对应标定编号 | B |
| L3（高） | 待试拍确认 | 待试拍确认 | 待试拍确认 | 待计算/核对 | K（μGy）或对应标定编号 | A、B |

为比较曝光强度影响，**固定kV、滤过、距离、照射野、探测器方向及读出/图像模式**，通过调整mAs获得不同档位。优先固定mA、改变曝光时长；不能这样执行时说明实际调整方法，各档分别记录mA和时长。曝光脉冲时长是实验条件的一部分，不能省略。

有条件时提供探测器入射空气比释动能K（μGy）的测量或逐条件标定，并说明测量位置、仪器和日期；本轮不要求每张都额外布置剂量计。若无法提供，如实注明，后续先研究固定设备下曝光设置/有效信号与残留的关系，不把mAs或显示亮度直接当作物理入射量。若只有未经验证的灰度映射输出，研究结论限于该输出域。

**顺序要求：** B包分3轮，每轮各拍L1/L2/L3一次，每组均独立复位；每轮随机或平衡档位顺序并记录。A包同样打散或平衡档位与物体顺序。避免所有低档拍完再一路升到高档，使曝光与时间漂移、累积历史混在一起。

原有中间档 `L4`（低中）和 `L5`（中高）保留为后续扩展选项，本轮无需执行。若三档已出现可重复趋势，再按需要补采，保持原命名，五档顺序为L1、L4、L2、L5、L3。

**每组按以下顺序执行，不可颠倒：**

| --- | --- | --- | ---: |

### 2.7 复位、时序与试拍检查

1. **复位流程固定并可追溯。** 写明所用设备复位操作、等待时长、暗读出次数，以及自动offset更新/校准等事件。DR使用设备实际可执行的复位方式，不套用CR成像板的光学擦除流程。
2. **稳定需由图像验证。** 试拍时在固定ROI检查clean暗图的背景均值、噪声和是否仍有物体轮廓，建立该设备本次模式的背景波动范围与检查容限。不得仅凭等待了固定秒数就声明无残留。clean_before/after明显不一致时记录漂移，分析前确认原因，不直接平均后掩盖差异。
3. **时序须一致。** 试拍确定最短可稳定执行的间隔，正式采集使用同一目标时序，记录实际值和计时误差。记录曝光开始/结束、曝光帧读出、Dark积分和读出事件；图像保存时间不能代替读出时间。曝光结束/关束事件定义一并说明。
4. **帧编号须真实。** 保存连续读出编号、曝光帧编号及额外/丢弃帧信息。Dark的积分窗口必须无新曝光；混合曝光帧单独保留和标记。无法取得真正第一暗帧时先反馈，后续只能按实际读出位置定义研究目标。
5. **量程须检查。** 试拍反馈每档的像素范围、端点/限幅值堆积以及处理映射说明；在分析ROI内避免饱和与未知裁剪。不能只凭图像看起来正常判断信号有效。
6. **合格试拍再开展正式矩阵。** 两组试拍用于检查流程，不保证估计充分的重复性；正式独立重复承担初步重复性检查。残留低于可测范围时同样反馈，不擅自切换模式、增强显示或提高到截断档来制造明显效果。

### 2.8 每张图需要记录哪些信息

随图像交付 `拍摄记录.xlsx` 或 `.csv`，**一张图像对应一行**。全局不变的设备/模式信息可以写入 `设备信息.txt`，逐图通过 `mode_id`、`reset_protocol_id`关联，减少重复人工填写。

| 记录字段 | 怎么填写 |
| --- | --- |
| `file_name` | 对应的真实文件名/相对路径 |
| `group_id` | 例如 `A_L1_OBJ1_R01`、`B_L2_R03`、`S_R01` |
| `frame_order` | 本组保存图像的真实先后顺序；与实际读出编号分开 |
| `readout_index`、`exposure_frame_index` | 实际读出编号和本组曝光帧编号；无曝光的S组曝光帧编号填不适用。说明额外/丢弃帧，不能仅把保存顺序当作读出编号 |
| `frame_type` | `clean_before` / `light` / `flood` / `dark` / `sham_dark` / `clean_after`；额外帧如实标记 |
| `xray_on` | 本帧积分期间ON/OFF；混合曝光另注明 |
| `exposure_level` | A/B组对应L1/L2/L3；无曝光S组填不适用 |
| `kvp`、`ma`、`exposure_ms`、`mas` | 实际曝光帧填写，mAs＝mA×ms/1000；无曝光帧填写OFF/不适用，通过group_id关联前序曝光，不编造Dark曝光量 |
| `incident_kerma_ugy` / `dose_calibration_id` | 可提供时填写测量值或逐条件标定编号；不能提供则明确标为无法提供 |
| `object_type` | A包OBJ1/OBJ2，B/S包NONE；关联固定摆位说明 |
| `capture_time`、`read_start_time` | 设备实际时间及含义；区分积分、开始读出、结束读出与保存时刻 |
| `integration_start_time`、`integration_end_time` | 可取得时填写；若只能取得固定积分时长/触发关系，在模式说明中给出，确保暗帧无新曝光 |
| `exposure_end_time` / `xray_off_time` | A/B实际曝光结束/关束时刻，说明定义；S组填不适用 |
| `dark_delay_ms` | A/B曝光结束至本张Dark开始读出的实际间隔；每张分别记录，其他角色填不适用。不能测量则注明原因与替代计时方式 |
| `sham_reference_time`、`sham_delay_ms` | S包等效触发流程参考事件及至sham暗读出的间隔；明确其与真实曝光流程的差异 |
| `reset_protocol_id`、`reset_wait_s` | 关联固定复位步骤和实际等待时间；流程变动须单独标注 |
| `detector_id`、`mode_id` | 同一DR探测器与模式的稳定编号；模式说明含帧率、积分、触发和处理链 |
| `repeat_round`、`acquisition_order` | 独立重复轮次及整批实际采集顺序 |
| `notes` | 漏帧、中断、隐藏读出、自动校准、参数变更、报警、复位不足、试拍身份等；无异常填无 |

一次性说明至少包括：厂商、型号、探测器编号、软件版本、读出/图像模式、处理链和内置残影校正状态、复位步骤、几何与滤过、计时方法和精度。记录开始/结束及明显变化时的温度或工作状态；可自动导出的日志优先使用，不要求为每张手工重复填写全部全局信息。

优先交付设备直接导出的原生全分辨率无损数据；不要手动裁剪、修图、截图、转8位、逐图归一化或修改灰度。保持真实有效位深和像素类型（包括设备原生的有符号或浮点表示），不同实例使用不同SOPInstanceUID。厂商格式须附可解码说明，不能将截图包装成原始DICOM。DICOM原始输出的名称本身不保证像素线性于剂量，仍需处理链/映射说明。

## 三、本轮研究范围与后续补采原则

本轮数据用于：第一帧残留可测性、固定条件重复性、物体轮廓对应关系、曝光设置/有效信号与残留的初步关系，以及简单模型扣除后Dark回归背景水平的验证。

分析分别报告绝对残留幅度和相对前序有效信号的残留比例；两者不是同一个问题。B包以固定ROI的信号与背景校正残留为主要量，均匀场不宜同时自由拟合不受约束的斜率与截距，背景由实测clean及S包约束。若不能确认像素映射，比例/系数限于该处理域，不宣称物理残留比例。

clean_dark提供背景与噪声参考，不是每个残影像素的无噪声真值。拟合与验证按独立循环分开，记录哪些组用于确定参数、哪些组保留作验证；同一循环的多帧、像素和patch不当作独立实验重复。A包每条件2次仅适合初步验证，不支持广泛泛化结论。

本轮没有当前物体在新曝光下的clean/ghosted配对，因此不用于宣称真实曝光图中的结构已经准确恢复，也不预设支持大规模深度学习训练。需要该方向时再补独立的当前曝光配对，不将本轮dark代替clean light。

**后续按结果补采：**

- 第一帧可测且重复稳定：继续比较曝光响应；需要曲线形状时再补L4/L5。
- 同条件波动大或S包漂移明显：先检查复位、时序、温度、读出及自动校准，针对问题补重复/对照。
- 残留未超过测量不确定性：报告该模式和量程内的未检出结果，优先确认测量灵敏度，不为追求明显图像而进入截断范围。
- 需要正式模型或泛化结论：依据预实验变异追加重复，并安排未参与模型开发的跨日期/新物体确认。

优先按完整条件、真实时序和有效信号交付；少量合格数据比大量条件不明的图像更适合本轮研究。

## 四、后续真实曝光图恢复的可选配对

本轮A/B包只在单次曝光后读dark。后续若要验证当前物体结构恢复，另安排静态当前物体A与前序物体B的配对：充分复位后曝光A取得clean_before；再次复位，曝光B取得previous；按定义的读出历史和间隔曝光固定A取得ghosted；再次充分复位，同条件曝光A取得clean_after。组内A的内容、位置、几何、曝光和处理链一致，期间额外读出全部记录。此处A/B是物体角色，不是本轮数据包编号。

参考需用clean重复和sham量化噪声、漂移与配准误差。`ghosted-clean`是包含上述误差的残留差分估计，不是无噪声的精确残影；不能逐像素相除就宣称取得真实alpha。只在有效、未截断的信号区拟合预声明模型，并使用独立循环确认；残留幅度增加也不等于alpha必然随曝光增加。

真实配对可保存到`data/raw/paired/pair_001/`，包含`previous.dcm`、`ghosted.dcm`、`clean_before.dcm`、`clean_after.dcm`和事件/条件侧车；不将本轮clean_dark冒充当前物体clean曝光。不预设50–100组或仅10组便足以确认线性模型、剂量曲线或训练泛化，按预实验变异与所需应用范围追加。后续采集按本节与第三节的补采原则执行。
